# Construction sound verification

## Implemented

Original stereo plastic-impact synthesis supplies restrained pouring/rattling, dry landing clicks and one crisp completion snap. No recordings, external assets, downloads or third-party sound licences are used. All impact waveforms are generated by `src/temple/audio.ts`. The project author dedicates the generated sound outputs to CC0; this does not alter licences for existing source code or dependencies.

The sound bed is generated from the same deterministic motion plan as the renderer. Nearby landings share perceptual clicks, with low-level irregular patter during falling waves. Cached impact shells keep first-enable preparation small. AudioContext creation and resume happen only after the user enables audio. The default is muted on each page load.

A single timeline source seeks into the current animation on unmute; replay replaces it. The renderer publishes its actual elapsed time after drawing, allowing progress reconciliation without changing animation timing. Mute cancels active sources; rapid toggles invalidate stale resume promises. Hidden tabs stop sound. Completion emits one short snap, with no repeating idle clicks. Reduced-motion/static scenes remain silent until an actual build occurs.

The accessible Mute/Unmute icon sits alongside Rebuild. Its accessible name, title and pressed state follow the audio setting. Model geometry, materials, camera fitting, motion plan and 3,900 ms animation duration were not changed for audio.

## Plastic-texture refinement

The updated mix replaces pitched shell tones with noise-excited, damped plastic resonances and a dry contact edge. The opening contains an irregular, gently fading handful of collisions, with softer recontacts. Pitch varies by ±6%, with deterministic variation in impact strength, stereo position and secondary-contact timing.

Landing clusters select an actual seating timestamp and favour the larger brick. The maximum constituent part volume selects small, medium or large shell textures; larger parts have lower-frequency, slightly stronger clicks. The primary accent is never randomly delayed. A fused body/edge transient supplies one completion snap.

The 48 kHz stereo listening preview is `.qa/audio-refinement/construction-plastic-pour-v2.wav`. Against the preserved baseline, full-preview RMS rose from 0.00555 to 0.01142 (+6.27 dB), with sample peak 0.334 (-9.51 dBFS). Gentle saturation retains headroom. These signal measurements do not substitute for listening review.

Production build and all 23 tests pass. Additional checks cover exact landing timestamps, larger-part selection, deeper large-piece textures and an audible opening pour. Playback ownership, default mute, unmute seeking, replay reset and completion handling are unchanged.

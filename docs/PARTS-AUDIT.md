# LEGO parts audit — 11 November 2026

Total: **2145 pieces**. Catalogue-backed: **2117** across **46 part types**. Custom architectural elements: **28**.

This consolidation starts from the approved 2,492-piece model and finishes at 2,145. All shrine dimensions, tower heights, material roles, interior voids and sculptural parts remain unchanged in this pass. Earlier iterations reduced the original 6,159-piece workspace model and regularised its tier heights; those changes are already part of the frozen benchmark.

## Verification scope

Official LDraw file headers were fetched on 2026-11-11. Saved evidence: `ldraw-verification.json`. The render uses lightweight procedural exterior approximations with catalogue dimensions, not imported LDraw CAD meshes. Underside cavities, mould details and hollow studs are simplified; this is not a certified physical build or a procurement list. Stone-inspired render colours have not been checked for retail availability in each part. LDraw content is CC BY 4.0; linked headers retain their authors and licence notices.
